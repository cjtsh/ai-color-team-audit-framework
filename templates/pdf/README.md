# PDF Report Generator — the typeset edition

Turns a completed Color Team report into a formal, print-grade PDF (cover page,
contents, document control, grade page with stat boxes, panel sections with the
color swatch table, findings ledger, attestation footer). The edition generated by
this template family has been published as the public audit record of a real
project — lawyers and trustees read the PDF; agents read the markdown; both carry
identical facts.

## Requirements

- Python 3 with `reportlab` and `pypdf` (`pip install reportlab pypdf`).
- A Times New Roman–family TTF on the host (macOS: `/System/Library/Fonts/Supplemental/`).
- For the cover page: any single-page A4 cover PDF — hand-built or from a cover
  engine; the merge script inserts it as page 1. (A cover is optional; the body
  generator works standalone.)

## Use

1. Edit `generate_report.py`: the palette constants (generate your own with any
   cascade-palette tool — keep one family, low saturation), the document strings,
   and the content sections marked with `# >>> CONTENT`.
2. Run it to produce `body.pdf`.
3. Render or obtain `cover.pdf` (A4, single page).
4. Merge: `python3 merge_cover.py body.pdf cover.pdf "[Report Title].pdf"`.
5. Brand metadata on the result and QA it (page consistency, no blank pages,
   fonts embedded) before publishing.

## Design rules that make it look like an audit, not a blog post

- One palette family; dark warm neutrals; a single accent. No rainbow.
- Cover: restrained — kicker, product name as the hero, one-paragraph summary,
  document ID footer. No emoji (ReportLab cannot render them).
- Grade honesty on the cover: the summary line states the actual grade and, if not
  CLEARED, the one-line reason. A cover that overstates the grade is a defective
  deliverable.
- Tables: dark header row, white text, hairline grid, alternating stripes; every
  cell a wrapped paragraph; widths computed from available width.
- The panel table carries a narrow color-swatch column — the one place the five
  colors appear, small and dignified.
- Footers on every page: document ID left, page number right, hairline rule.
- QA after every build: automated checker plus eyeballs on the cover, the stats
  page, and the swatch table at 100% zoom. (In real runs, human eyes caught a
  clipped cover line and a stray placeholder the automated QA missed.)
